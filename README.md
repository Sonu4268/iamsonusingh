## Tech stack
Plain HTML and CSS. No framework and no JavaScript. Fonts: Syne and DM Sans (Google Fonts).

## Host it free on GitHub Pages
1. Create a public repository named `yourusername.github.io`.
2. Upload all `.html` files, `style.css` and `resume.pdf` to the repository root.
3. Go to Settings, then Pages. Choose branch `main` and folder `/ (root)`, then Save.
4. Open `https://yourusername.github.io` after 1 to 3 minutes.

## How to edit
- Change text: open the page file on GitHub, click the pencil icon, edit and commit.
- Change colours: edit the values at the top of `style.css`, under `:root`.
